# tetris — BrickGame Тетрис

Консольный тетрис на C (ncurses) с разделением на backend (логика на конечном автомате) и CLI-frontend.

## Управление
| Клавиша | Действие |
|---|---|
| `S` / `R` | Старт / рестарт |
| `P` | Пауза |
| `←` `→` `↓` | Движение фигуры |
| `Пробел` | Поворот |
| `Q` | Выход |

## Сборка
```bash
cd src
make            # собрать
make run        # запустить
make test       # unit-тесты
make dvi        # документация
```

Полное задание — в [README_RUS.md](README_RUS.md).
